# 🐳 Dockerized Static Website

A simple static website built using HTML and CSS and containerized using Docker.

## 📌 Project Overview

This project demonstrates how to containerize a static HTML/CSS website using Docker and Nginx.

The application is packaged into a Docker image and runs inside a Docker container.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Docker
- Nginx
